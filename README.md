Implementação de uma lista em Java com controle de capacidade,
desenvolvida para a disciplina de Estruturas de Dados.

Funcionalidades;
✅ Inserção por índice  
✅ Remoção por valor/índice  
✅ Busca de elementos  
✅ Controle de capacidade máxima  
✅ Exibição com elementos nulos  
✅ Ordenação crescente/decrescente
